# C01 可编辑矢量蒙版（42.20）

本包基线 `ae349e504f85eb6f29c75d65ee911a907ff209a4`（PR #18）。功能源码 **`87539f507db4fd88c9430ae2b4573eb075d45f65`**。最终定向测试 **100 项通过**（引擎 82、原生 18，含显式运行的隔离资产链）；Rust / Slint 原生测试构建通过。构建和样例摘要见 `verification.json`。本包没有重建应用安装包，旧包不代表此源码。本目录 PNG 是后台渲染证据，不是 UI 截图。

## 数据与交互

保留每个节点一个蒙版槽。`LayerMask.vector` 存在时，`VectorMask` 中的闭合 `VectorShape` 和内在尺寸是唯一源数据，`pixels` 仅命名派生覆盖率；不存在时保持旧位图语义。已有任一种蒙版都不会被新增操作覆盖。路径继承原有 Knot 双控制柄与 tiny-skia，未增加新矢量引擎。

创建入口提供矩形、椭圆和四锚点闭合贝塞尔路径，以当前图像内在矩形或文档区域内缩 12.5% 的范围开始。点击蒙版缩略图进入现有锚点/手柄编辑，复用同一历史事务和屏幕坐标换算；可返回图层操作。矢量目标下笔刷、橡皮、选区像素填充不进入派生缓存；没有自动栅格化。普通形状图层继续走原编辑路径。

图像蒙版使用图像内在尺寸，图层变换只应用一次。组和调整层支持文档空间蒙版；它们没有图像变换，链接按钮不显示。图像解除链接冻结当前放置；重新链接把几何换算回当前图像空间以保持文档位置，再随图层移动。旧位图没有 anchor 时仍按原文档空间绘制，旧首次变换补 anchor 的路径保留；本包没有新增旧位图的链接切换 UI。

## 渲染与保存

覆盖率从不透明填充几何的 alpha 生成，保留抗锯齿灰度，不从原彩色填充的红色推断。矢量外部为 0，旧位图越界为 1。CPU、GPU、命中与 clips_to 使用相同的覆盖率映射；缓存帧身份变化会使 GPU 重新上传，撤销/重做沿原重置路径。

不同源图/画布尺寸的测试发现了旧 GPU 剪贴覆盖率错误：源图尺寸被当作画布尺寸，源图外还返回了 backdrop 颜色。修复限定在覆盖率 pass：使用真实画布尺寸，源图外返回零覆盖率。共享 GPU 渲染回归单独验证。

新增内容用项目 v6 门控，旧 v1–v5 保持可读。保存几何及尺寸，不保存矢量覆盖率 PNG；重开先校验几何、闭合、有限坐标、节点数和像素预算，再重建缓存。错误版本、损坏几何或派生缓存 ID 与其他源共享会拒绝，加载失败不替换当前文档。LayerMask 不再 Copy，复制和历史快照深复制几何，副本缓存采用新 PixelId。

## 验证方式与边界

- 引擎测试检查 alpha/灰度/边界、非法源、文档映射、命中和剪贴。GPU 矢量专项强制要求真实 wgpu 适配器，不能以无适配器静默返回计通过。
- 原生定向测试经真实 CanvasPane 编辑事务覆盖三种创建、变换坐标下的锚点和控制柄、笔刷拒绝、已有蒙版保护、链接/解除链接、独立副本、撤销重做、组与调整层、v1–v5 旧文件、v6 重建和损坏加载保护。复用原普通形状、旧蒙版与保存相关用例。
- 完整样例测试将测试二进制复制到独立临时目录，以相邻空 `portable/` 隔离全局资产库。测试首先断言数据根目录正确，再创建/编辑/变换/复制/历史/保存重开，比较 CPU/GPU/PNG，执行真实 CanvasExportJob 登记、重试复用和文件摘要核验。使用合成素材，没有账户登录、供应商调用或生产服务。

构建和定向命令、准确通过数见 `verification.json` 及对应日志。初步失败和已修复结果不混算为最终通过。

共享桌面禁令保持：没有启动 QA 应用、激活/移动窗口、注入鼠键或切换输入源，没有新建系统账户。真实按钮点击、手柄拖动、窄窗/主题/IME 的实窗效果仍未验；R3 实窗和生产两设备继续未验。没有安装、部署或修改持久凭据，也未唤醒旧写入者或 Astra。
