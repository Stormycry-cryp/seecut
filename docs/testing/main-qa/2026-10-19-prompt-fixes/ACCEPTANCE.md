# 一次性实窗验收步骤（待窗口工具恢复）

只运行最终候选 `SeeCut-Prompt-Fixes-QA.app`，API 固定 `127.0.0.1:18743`。先确认这是合成服务，禁止借用生产凭据。记录 App 的源 SHA、进程实际路径、包摘要、服务夹具模式；以本目录 manifest 为准，不用旧截图当本次通过证据。

四个入口在同一候选依次完成：生成页图片/视频模式、原生画布灵感推荐、Flow 图片节点、Flow 视频节点。原生两处共用 GenerationForm；Flow 两种节点共用 promptInput 和 PromptRecommendations。

| 场景 | 操作 | 必须核对 |
| --- | --- | --- |
| 普通应用 | 带两张参考素材输入草稿，等推荐后点击一条 | 请求只发一次 rewrite；回填保留素材顺序，输入/发送恢复；不产生媒体任务或扣点 |
| 快速输入点击 | 已有推荐时连续输入最后几个字符，立即点击 | 请求使用点击时完整文本；不能用 200 ms 之前的文本；原生有排队期间变更则取消并解锁 |
| 未发出即离开 | 原生点击后立即切页，或关闭画布推荐面板 | 待处理选择被取消，不产生 rewrite 请求；返回后输入和生成可用。若请求已发出，按下一项验 |
| 请求中离开 | 给合成改写增加响应延迟，切页/关面板/切画布/换账户后再返回 | 旧结果不回填；真实在途请求期间不接受第二次改写；结束后锁释放 |
| 新草稿抢先 | 延迟回复期间通过已有编辑/节点更新路径改变文字或参考，再让旧请求结束 | 保留最新草稿及参考；不回填旧结果。包含“改走又改回”和切图后切回 |
| 失败 | 合成服务返回改写错误 | 原文、参考及原恢复备份不变，忙碌结束，可明确重试；不生成媒体 |
| 撤销 | 成功改写后使用恢复/撤销入口 | 原生现有“恢复原草稿”恢复提示词、素材、模型参数和模板信息；Flow 撤销恢复原富文本及引用，不清空引用素材 |
| 撤销隔离 | 成功后改文字/引用或切账户/画布，再尝试旧撤销 | Flow 不用旧备份覆盖新编辑或新作用域；原生沿用账户、素材版本、模型参数校验，拒绝时保留当前草稿和备份 |
| 无自动生成 | 比较应用、失败、撤销前后服务任务及账本 | recommend/rewrite 之外没有生成提交；媒体任务数和计费记录不增加 |
