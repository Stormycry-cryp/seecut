## 修正范围

1. Flow 共用提示词输入组件在点击和回填前读取真实草稿。XSender 的输入回调会排队，因此 DOM input 事件同步标记草稿变化；最后几字尚未写入 Vue model 时读取当前文本节点。文字、素材和上下文同步监听改变版本，原 200 ms 定时器只负责推荐调度。改写前及响应返回后再次读取当前状态，迟到结果不能覆盖后来的文字、引用、切图或关闭状态；“改走再改回”仍会使旧轮次失效。
2. 原生推荐按钮记录点击时提示词、草稿修订与上下文修订。下一 tick 只接收仍有效的选择，取消未发出的选择会解除 UI busy；真实在途 rewrite 保留 pending 身份和防重入锁。账户 epoch 变化沿用原隔离逻辑；页、画布面板、模型、参数、素材与草稿变化都参与过期结果判断。
3. 原生改写在请求前复用 `inspiration::capture_draft`，成功后挂到原有 `inspiration_backup` / “恢复原草稿”入口。恢复继续走原模型、参数、素材版本、账户及未知生成操作校验，包含参考素材；失败或旧结果不替换原备份。正在改写时，原模板应用及恢复入口均不可重入。
4. Flow 增加图标式“撤销改写”，通过既有富文本 model / reset 路径恢复改写前的文字和引用标签，参考素材本身不变；仅能撤销当前作用域中尚未被后续编辑替代的改写，不将旧备份回填到新账户、画布或素材集合。

没有新增解释段落、另一套生成接口或计费路径。Jev 仍从 SeeCut 自有候选中选择，GLM 5.3 Flash 只在明确点击后改写；撤销不调用模型、不自动生成。
