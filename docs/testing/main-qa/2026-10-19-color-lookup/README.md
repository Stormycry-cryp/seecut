## 使用与资源

新增颜色查找（kind 10）：在原调整入口创建，参数区展示 LUT 短名、导入/替换图标和强度。未导入时明确显示“未选择 LUT”，画面保持恒等；强度 0 同样恒等。普通调整混合保持原 alpha；非普通混合仍采用原 CPU source-over 语义，可能增加半透明 alpha。

支持 UTF-8 `.cube` 三维表，TITLE、DOMAIN_MIN/MAX，以及互斥的 Resolve 风格 LUT_3D_INPUT_RANGE。网格 2–65（覆盖 17/33/64/65），输入文本不超过 32 MiB，数据行数必须完整；拒绝一维/组合、未知变换字段、重复/迟到头、非法域和非有限值。单行最多 4096 字节，标题最多 128 字符，输出表值限 ±1000000，避免浮点溢出。每表 RGB 浮点数据最多约 3.15 MiB，GPU 上传约 4.2 MiB，上传缓存只保留一表。

输入使用画布现有 straight encoded RGB 字节归一化到 0–1，不隐式转换 gamma。域映射后夹取输入坐标，CPU/GPU 使用一致的四面体插值和强度混合，最后夹取输出并量化。GPU 使用 float32 表及显式采样，无可选浮点过滤特性要求。对恒等字节的判断按整数值进行，修复了归一化浮点尾差导致非普通混合误生效的问题。

解析结果为不可变共享资源，包含规范化 float32 数据、域和 SHA256；标题不参与内容摘要。整个资源内嵌 v5 工程，不保存外部绝对路径。复制层共享只读数据，替换与参数历史独立；不同历史表计入既有 256 MiB 历史预算。工程 manifest 上限 64 MiB，超过时保存失败并保留旧包。旧 v1–v4 仍可读，未含新类型仍保留原版本；旧应用明确拒绝 v5。

文件选择与解析回包冻结项目 generation、binding epoch、图层、修订、单调修订时钟和导入序号。取消不修改；解析失败、换项目/图层、后续编辑、编辑后撤销、新导入及进行中的手势均不能让旧回包覆盖当前草稿。成功才提交一条历史。导出复用 PNG 默认入库与已有去重/回插链。
