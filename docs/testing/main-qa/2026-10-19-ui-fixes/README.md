## 改动

- **F1 推荐回填与撤销**：将编辑器富文本模型和纯文本的回填作为一个事务，等待 Vue 的 next tick 完成再重新核对草稿；中间状态不清空撤销或重新进入等待。上下文包含账户/工程/画布/节点，仍拒绝过期响应和后续用户输入被撤销覆盖；原富文本模型独立快照恢复。
- **F2 调整控件同步**：属性滑块使用统一的本地控件值，模型发布显式刷新滑块和数字输入；选层、撤销、重做继续经过现有模型发布。数字字段只在按住鼠标时拖动，开始和结束拖动接入原手势历史。
- **F3 画布导出登记**：在 UI 线程冻结与生成链一致的账户/服务范围，后台对冻结 PNG 字节求摘要，以账户范围+内容作为全局资产库登记身份。重复导出返回同一素材及版本，真正变化的内容保留为另一项；操作完成/重试仍使用原流程。未清理、合并或覆盖旧资产，不推断旧无账户记录属于某个登录账户。
- **F4 Flow 浮层**：SeeCut 内嵌画布的操作区按可见画布范围定位，约束宽度、限高滚动，随窗口/缩放/节点移动重新计算；不写节点位置或画布变换。主生成参数可换行，次要操作收进“更多”，不可用项折叠后不再横跨相邻节点。普通 Toonflow 模式保留既有位置策略。
