# C02 — 自然饱和度与黑白调整层

起点 `c97aa9406055cf6ae57302f51dae0f27b14513dd`；依据私有计划 `db6000e` 第 42.13 节。仅增加这两种调整，原七类、曲线、位图蒙版、文字及 Flow 集成沿用。

## 行为与公式

- 自然饱和度 kind 8，参数 amount ∈ [-1,1]，默认 0。令 HSL 饱和度为 S，amount≥0 时 S′=S×(1+amount×(1−S))；amount<0 时 S′=S×(1+amount)。保留 H/L，夹取到 [0,1]。零值直接恒等；灰阶与满饱和颜色在正向增强时不变。
- 黑白 kind 9，三个独立 RGB 权重均 ∈ [0,2]，默认 0.299/0.587/0.114。gray=clamp(R×red+G×green+B×blue)，三个输出色通道相等。权重不归一化，可调亮度；三者全零为黑色，不出现除零。
- 参数拒绝 NaN/Infinity；控件与业务层使用相同范围，黑白显示三位小数并重置到各自默认值。类型名称与参数来自原调整接口。
- 复用原调整层蒙版、不透明度和混合规则。普通模式保持底图 alpha；非普通模式沿用既有 CPU source-over alpha 规则。GPU 补上原先漏掉的非普通混合，和 CPU 的未改变像素短路保持一致。
- 调整入口分成两行，并在压缩面板时可滚动；没有新增悬浮面板。参数拖动合并一条历史，取消恢复原快照，Agent 切层与 UI 切层同样取消未提交的参数手势。
- 含新类型的工程写版本 4；仅旧内容仍写版本 1/2/3，新读取器接受 1–4。旧应用会拒绝 v4，不能用旧版继续编辑新调整。新类型伪装为较早版本会被拒绝，不静默移除图层。
- PNG 导出复用正式默认入库与不可变资产版本登记；重复同一登记 ID 只保留同一资产版本。画布回插复用同一资产引用。
