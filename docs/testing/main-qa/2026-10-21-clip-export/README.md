## 已实现的行为

同一捕获Catalogue用于flatten、音频、普通clip、Layer和逐帧shader参数。原入口保留，并继续共用同一个渲染主体。GPU证据仅覆盖计划与uniform，没有实际GPU像素验收。

StrictLocal贯穿probe、paced/seek视频、ReaderPool、音频解码、mix和mux；预打开唯一普通主文件，CUSTOM_IO和拒绝额外I/O回调在打开容器前生效，配合实际demuxer白名单。拒绝状态不能在seek或EOF被吞掉。合法1000Hz PCM WAVE被本机通用FFmpeg probe误判为MPEGTS的原场景，已通过RIFF/RF64+WAVE字节签名选择wav修复并重验；不按文件后缀决定。当前FFmpeg未安装DASH demuxer，DASH文本拒绝不能证明安装该demuxer后的行为。

严格渲染使用CPU合成，实际编码保持原硬件首选和软件回退。普通clip、反向/seek及Layer真实执行失败会阻止发布；原手动路径保留既有容错。真实Layer回归先用合法模板构造不可用FFmpeg滤镜，严格路径报错且不调用发布钩子，兼容路径保留原画面，成片完整解码核对。

`FrozenExport`精确选择活动时间轴，复制实际媒体、标题PNG和完整遮罩目录，按块摘要、去重及前后文件身份核对。源文件之后改变不影响副本；副本缺失、替换、多出条目、取消或超过资源上限明确失败。实际Project保持原样，标题缓存和当前系统字体仍按现有Titles逻辑处理。第一批拒绝自定义目录包和声明LUT；任意外部模板及字体字节冻结不在支持范围。

发布前钩子拿到实际完整临时成片，只调用一次；无声和真实混音/mux两路均完整解码验证。拒绝不发布、临时文件清理；最后输入核对失败不调用外部钩子。钩子成功后的迟到取消不能被解释为从未发布，最终独占发布也可能失败。当前钩子不提供原生权限或CAS。已发布后输入变化/取消的错误保留实际路径，不覆盖已发生的结果。

`verify_output`独立新开普通文件，前后全文件SHA、身份/修改状态核对，严格probe与准确codec/尺寸/有理帧率检查，软件逐帧解码至EOF。实际CFR位置逐帧核对零起点序号，准确帧数必须一致；每条音轨完整流式解码48000Hz双声道F32，核有限样本、时长与AAC误差。正常静音允许，peak/RMS不代表已试听。H264、HEVC及AV1在本机均实际编码、完整软件解码通过，没有因缺编码器跳过。

默认Decoder会把源帧缩放到最初probe尺寸；新增SourceFrameLimits在原始frame收到后、任何缩放/滤镜/seek丢帧/pacing之前检查尺寸，codec打开前设置像素上限，软件重新打开保留该限制。合法H264单流夹具前4帧64×64、后4帧128×128，先证明旧Decoder将8帧全部归一，再证明成片核对明确拒绝。旋转、coded padding、seek、pacer和坏参数另有实际检查。像素上限是codec约束，不代表进程或probe的全部内存分配均被限制。

## 实际失败与修复

初轮输入副本18项中16项通过，2项因测试夹具失败：无后端效果包已在解析期拒绝；macOS socket路径超出SUN_LEN。仅修复测试构造后18项通过，生产逻辑不变。

原多帧率和完整编辑导出曾分别读到149/150帧、868/869帧。真实Rust诊断确认编码和mux均保留全部包，独立FFmpeg正常解码也少一帧；MP4最后sample时长为0，edit list排除了末帧，忽略edit list可读回全部帧。最小修复在重采样包时间戳之前，仅给非正duration补1个编码器tick，保留已有正时长。新增回归完整核对150/869帧及绿色末帧，同时原两条integration恢复通过，未放宽断言。

成片模块初轮13/17通过，4项被同一编码时长问题提前阻止；修复Encoder后17项全通过，未改核对期望来适配错误文件。首次失败日志与修复后证据均保留。新增模块一处Clippy等价范围表达式整理后，host125项、格式及严格Clippy重新通过。
