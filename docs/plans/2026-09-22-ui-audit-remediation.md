## 已确定的产品细节

- 回填遇到缺失素材时保留原顺序与引用位置，显示可替换的缺失项；不能悄悄删除后让 @图片编号指向别的素材。模型不可用时先恢复可用输入，再明确要求选择模型；无自动提交。
- 批量资产选择与资产页管理选择分别存储。切换来源或团队时清理不适用的选择，显示实际选中数量；一次确认才批量添加。画布打开仍为单选。
- 图片共用应用内预览；视频和音频保留明确的外部播放动作，不把静态海报当作已支持内嵌播放。预览保留引用、剪辑、画布入口，并依据类型限制。
- 900×640 下参考封面保留可辨认尺寸，采用一行素材带和展开查看；提示词有独立稳定高度；参数靠近生成按钮，优先展示模型、尺寸/比例、视频时长/声音。
- 资产统一完整缩放，维持以图片为主体的网格；图片上操作统一底板。模板参考图扩大，并展示剩余数量。
- 画布数值复用现有输入组件，颜色提供常用色、颜色选择、HEX 和画布取色；图层图像和蒙版分别可见、可选择。

## 实机反馈：导入图片闪退补修

2026-09-22 用户报告打开图片、资产入口和拖拽均会闪退。三份实际运行日志均为 wgpu `CLEAR_TEXTURE` 未启用的校验 panic。共享窗口设备使用默认空 features，独立画布测试设备却额外申请了该能力，导致此前测试未覆盖实际设备契约。原 173853c 应用包存在阻断缺陷。

修复改用标准 render-pass 透明清空，并移除独立设备的额外能力申请。真实 Apple M4/Metal、空 features 已复现原故障，修复后画布核心 138 项通过；新增使用窗口实际 `Gpu::acquire` 的四格式文件导入与 GPU 像素读回回归。客户端完整 100 项、画布核心 138 项以及包含测试目标的 Clippy 均通过。完整优化 app 配置重新交付，最终包状态见修复报告。证据位于 `../outputs/canvas-import-crash-20260922/`。
