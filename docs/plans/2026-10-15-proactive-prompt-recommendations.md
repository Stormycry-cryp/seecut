# SeeCut 主动提示词推荐与改写

来源：用户明确指定会话 `01a13eb8-5699-7033-bc68-da683d8a12bd`，并确认 Jev 从我们提供的提示词候选中选择。实现位于当前 SeeCut 工作树；保留 R1 顶部简化、生成结果自动进入现有资产库，以及在途 R2 Flow 工具链改动。

## 产品行为

- 候选使用 SeeCut 现有的六条原创提示词。仅传提示词、标识和短名称，不复制 FD 的私有模板快照或凭据；个人模板需先有账号归属，当前不纳入上传。
- Jev `jev-1.14-free` 直接接收代码组装的当前输入、图片和最近 5 条同账号生成提示词；不经过前置语言模型。按候选概率取最多 3 个不同条目，不能输出池外条目。
- 生成页以及本次截图所指的 Flow 画布生成节点使用同一套交互与账号级刷新间隔。原生排版画布增加“灵感推荐”浮层，直接复用同一生成表单、推荐组件与生成提交入口，不新增独立生成资产库。
- 有输入或参考图时，停止修改 1 秒后推荐；各入口从上次开始时刻共用至少 10 秒间隔。等待期间合并最新输入，不并发请求，不丢失最后一次编辑。清空、换账号、切项目或节点后丢弃旧回复。
- 输入框旁展示一行“为你推荐”与最多 3 个短按钮（最多 5 字），加载时“正在匹配…”，等待刷新时保留旧条目并显示“等待更新”。更新时短暂描边提示，遵循减少动态效果设置。失败静默保留输入；429 遵循 Retry-After，不无限重试。
- 点击时冻结输入与所选完整提示词，显示“应用模板中”，暂时禁用编辑与发送。GLM `glm-5.3-flash` 复用 SeeCut 服务端配置进行改写，输出接近模板篇幅，保留句式、替换主体、合并用户要求，不扩写套话。成功回填并聚焦；失败保留原文/图片并允许重试。回填本身不触发推荐；下一次用户编辑才触发。
- Jev 支持图片；现有 SeeCut GLM 接口明确不支持图片。不得把图片发送到该纯文本 GLM 接口或声称其识别图片。改写保留参考图，并依据用户文字及模板表达“以参考图为准”。
- 推荐与改写不扣用户点数；服务端限制频率和并发，记录实际上游用量（未知不伪造为零），不触发生图。用户自行点击生成后继续现有模型、参数、资产注册流程。

## 实施顺序与验收

1. 收束在途 R2 合成验证并保存准确证据。R2 的文字节点已通过正式工具创建且保存；后续操作因权限/审批中断而取消，不能声称全链完成。原生 Agent 与 Flow 同屏及顶部控件移除已实际截图。
2. 服务端建立受登录保护的推荐/改写接口：严格验证候选、图片、输入上限、去重、未知候选、幂等与账号隔离。复用 GLM 服务配置；Jev 只读取服务端 `BEATAPI_API_KEY`，默认缺失时能力不可用。不得从桌面钥匙串复制密钥到服务器。
3. 原生宿主提供候选、近期历史与服务代理，账号身份由宿主注入；网页不拿到凭据。原生生成页与 Flow 使用共享服务刷新约束；所有异步回填核验账号与草稿版本。
4. 完成窄屏、浅色、深色、键盘可达、加载/等待/失败/重试的 UI。Flow 绑定实际节点草稿；原生排版画布复用生成表单与提交入口，浮层保留画布视口，输入期间屏蔽画布工具快捷键。
5. 定向测试调度时间边界、失败与过期响应、幂等、模板内排序、改写长度和原图保留；本机合成服务全流程 UI 验证。真实供应商调用与生产部署另受当前授权边界约束。
