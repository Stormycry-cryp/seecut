# SeeCut 工作区与画布收尾

## 交付行为

- 主导航固定四项：生成、剪辑、画布、资产；账号与积分由底部账户入口进入。
- 画布拥有独立工作区，切换页面保留文档；剪辑恢复原本的预览与时间线布局。
- 资产内部切换个人资产、团队资产、生成模板。个人素材默认本地；上传团队需要明确操作。
- 个人资产以预览网格呈现，支持日期浏览、类型与来源筛选、搜索、收藏、批量回收与恢复；素材可用于生成、剪辑，图片可打开到画布。
- 生成模板包含提示词、模型参数与参考素材，支持创建、编辑、删除和应用；应用只回填参数，缺失素材明确反馈。
- 沿用原生 Slint 组件与主题，参考提供图片的组织方式；保留后续 Agent 调用接口，不展示空 Agent 面板。

## 实施与责任

1. Sol/high 修复画布核心的笔画收尾、坐标转换、重复开图残留与 GPU 尺寸保护，并补充像素级回归。
2. Sol/high 实现个人资产收藏、批量操作、日期字段、本地模板持久化、工作台桥接、串行验证与原生包交付。
3. Astra/medium 实现导航、独立画布、资产卡片、模板 UI 与隔离截图 fixture。
4. 主代理负责范围判断、差异审查、验收判断与 PR 决策，不承担业务实现。

## 验证

- 蒙版绘制前后原图 RGBA 完全一致；笔画最终数据与引擎 flush 一致；重复开图后不保留旧像素。
- 收藏及模板重启仍存在，兼容旧索引；批量操作仅作用于选择项；模板应用不提交生成。
- 四项导航正确选中、画布可独立打开、个人资产能进入对应工作区、切页保留编辑状态。
- 运行相关 Rust 测试、Slint 编译和原生构建；构建前检查内盘空间。更新现有 Preview 客户端并核对产物。
- Windows 构建与实机、可见 UI 操作及性能证据分别记录；缺少证据不写通过。遵守用户禁止 CUA 的要求。

## UI 重做决定

- 四工作区使用同一深色主题与 72px 导航；正文 13–14px，去除与左轨重复的页面标题，操作图标 18px、点击区至少 32px。
- 资产顶部仅保留页签与上下文动作，搜索与筛选宽窗同区、900px 窄窗分两行；卡片以预览为主，常驻名称、必要信息及“使用素材 / 更多”文字入口，收藏和批量选择可键盘操作。
- 模板卡片固定名称、模型参数、提示词、引用与底部操作层级；保存当前配置使用现有模板合同。
- 画布采用 44px 文档栏、48px 左工具列、中心画布与可收起的 250px 图层/属性栏；保存工程和导出图片分开，参数显示数值和滑杆，保留蒙版、调整、曲线、选区、拖排序及未保存确认。
- 界面迭代由 backend 串行 quick 构建；合成数据截图覆盖五工作区宽窄、菜单、模板保存、画布未保存与属性收起、生成登录前/模型失败/空结果。主代理审图后再做完整优化交付构建。

- 生成页左侧 380px 为有序参考封面与提示词，底部参数摘要打开完整设置；右侧默认结果网格。封面单击应用内放大，回填恢复历史输入，引用仅追加结果素材，三种动作分开。历史输入与内嵌视频能力须由真实后端合同支撑。
- fixture 首次渲染后等待动画稳定再截图；页面切换清理状态后打开菜单并断言。宽窄图补生成参数、大预览、视频 9 参考及不同任务状态。
