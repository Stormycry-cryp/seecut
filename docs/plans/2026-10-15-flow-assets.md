# Flow 与 SeeCut 个人资产库接入

目标是让 Flow 使用现有个人资产库，不再维护一份独立媒体库。本轮覆盖图片、视频、音频；文本沿原节点与文档面板自动保存。个人库沿用当前本机共享语义，未登录也可使用；团队云资产沿现有团队入口管理。

## 原生能力

`toonflow_bridge.rs` 复用 `personal_library`，提供资产搜索、类型筛选、24 条分页、缩略图、固定版本读取、复制进项目及项目媒体入库。私有桥传路径，网页只接收资产身份和同源媒体地址。操作起止核对原生会话，避免途中切换账户后继续操作。

导入先校验原资产版本，将媒体原子复制到项目 `assets/imported`，来源写入 `.seecut/assets`。生成参考复用经过校验的原资产身份；原设备资产不可用时项目副本仍可使用。手动保存避免重复登记，现有生成任务登记与去重规则保持。

## 本地服务

新增 `seecutAssets.ts`，由 `seecutHost.ts` 挂载 `__seecut` 下的列表、缩略图、内容读取、项目导入和项目输出登记接口。项目导入受现有写入屏障保护，完成后触发保存与同步。媒体按需流式读取，支持视频 Range，不把大文件作为缩略图。

## Flow 交互

嵌入模式资产按钮打开 SeeCut 资产面板，支持搜索、类型筛选、分页、预览、添加到画布，以及连接兼容生成节点用作参考。媒体输出沿原节点保存入口加入个人资产库。普通 Toonflow 模式保留原功能。

打开面板才查询，搜索防抖，过期响应丢弃；图片缩略图懒加载，预览点击后再加载原媒体。不新增轮询。

## 导航显示与画布布局

原生浏览器使用 SeeCut 当前页面底色。首次进入须同时完成文档加载与 Vue 页面挂载，随后通过同源 `seecut:view-ready` 通知显示；错误页也发送通知，设置读取在嵌入模式下限时 10 秒。切回 Flow 复用原浏览器，不重新装载项目。

嵌入工作区为顶部项目栏留出 52 像素后，由上下边界计算画布高度，避免底部资产库与缩放控件被裁切。

## 已获得的运行证据

- 原生 SeeCut 个人库四项素材可在 Flow 预览、搜索和筛选，图片可直接连接生成节点作为参考；视频与音频正常加载。未触发付费生成。
- Flow 上传图片保存到个人库后，原生资产页显示第五项；重复保存已有素材不增加条目。
- 验收项目保存并重开后保留五个节点、一条参考连线、项目内媒体及来源记录；原生窗口实际显示资产面板。
- 24 个并发缩略图请求全部返回非空 200，合计 1313 毫秒；视频字节范围请求返回 206 和准确的 100 字节。该结果来自本机小型验收库，不代表大库性能。
- 720 像素视窗中，画布从 52 到 720 像素，资产按钮底边为 701，页面不再多出 52 像素滚动区域。
- 最终原生构建与签名检查通过。首次进入、从原生画布和资产库返回 Flow，以及深浅主题往返未复现整页黑屏；离散截图共 18 张，不能替代连续逐帧录像。
- 更新前正常退出旧实验版，复制并校验 76 个文件；新实验版实际重开项目 312 后，画布与文档仍与原文件逐字节相同。旧包及原数据保留。
- Web 和 Host 构建通过；完整 Web 类型检查仍缺少上游生成的 ElectrobunConfig，不用宽松声明绕过。正式云端往返、真实付费模型和 Windows 不包含在本轮运行证据中。
