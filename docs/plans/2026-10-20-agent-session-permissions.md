# Agent 浮层与会话权限修复

用户要求修复展开面板、收起按钮外围多余矩形底板，并把权限收敛为互斥的“允许读取”／“允许页面操作”。页面操作持续到本会话结束或显式撤销，不使用五分钟续租、不扩展超长时间戳。

## 已定位

- `toonflow_webview.rs` 把原生浮层 footprint 扩大 8px；`toonflow_overlay_macos.rs` 用直角矩形挖空 WebView，并按矩形让出点击。这样露出原生页面底色，不能合成透明阴影。已在确切 272bcf1-Run 实窗深浅色、展开和收起复现。
- `assistant-floating.slint` 缩放手柄没有固定 Path viewbox，路径会自适应填满角落。需要固定坐标并保持在圆角之内。
- `editor_mcp_write_registry.rs` 的授权统一使用五分钟 deadline；`editor_mcp.rs` 向 UI 发布剩余分钟并对 Grant/Renew/Revoke 分别处理。
- `agent_ui.rs::sync_lease` 遇到写 token 改变会关闭整个运行时连接。运行时当前只在 initialize 接受 token，MCP 子进程通过环境获得它，须一起支持可信宿主的权限变更。
- 会话切换在 `new_session`／`select_session`；账户已有集中撤销入口。授权不能进入历史文件。Flow 和原生画布的精确操作 permit、版本/对象检查须保留，切档时立即清除旧 permit。

## 实施与验收顺序

1. 浮层：用同一个实时圆角路径定义显示与点击；Flow 不挖阴影边距。保留页面尺寸和正常面板／输入框。实际圆角外双击应交给 Flow，内部操作不得影响画布。多页、深浅色、展开收起、窄窗与缩放留原始 PNG。
2. 宿主授权：为固定 Agent 引入明确会话生命周期授权，外部手动 MCP 客户端原有期限不扩大。新会话、切换会话、退出登录、账户切换撤销固定 Agent 授权和精确 permit；同一有效会话重连保留授权。用虚拟时间覆盖超过旧 300 秒、撤销和跨范围拒绝，保留操作去重历史。
3. 运行时与连接：新增可信宿主权限更新协议，在原 Agent 会话内更新执行权限；需要替换 MCP 凭据时只重建编辑器传输，不重建推理会话。权限更新期间禁止新输入／旧确认，降档即清除写权限并取消未执行确认。旧或错误会话、错误版本、失效 token 拒绝；不重发输入或工具。私有 runtime 仅在既有独立 worktree 修改和本地组包，不发布到公共仓库。
4. UI：默认权限菜单只显示两个互斥选项；去掉续租、倒计时及独立撤销写按钮。切回读取就是撤销写入。保留正常连接、单轮 120 秒超时、高影响动作确认、UNKNOWN 原操作核账。
5. 冻结源和 runtime 版本，定向测试后更新已批准的运行副本。实际切档连接不断、旧确认失效、读操作可继续；保存超过旧期限证据和回归截图。最后更新 PR 与剩余项。

## 边界与回滚

仅当前唯一写入者；没有生产、凭据、外部上传或真实付费调用。封存包保持不变。恢复旧运行二进制／runtime 时必须成对恢复协议版本，并关闭现有测试会话，不能跨版本恢复临时授权。Agent 合成生成闭环先停在既有断点，不以其他验证冒充通过。每阶段读新鲜官方七天额度；剩余不超过 30% 或不可读即停。
