# Security Policy

Security reports about the current Seecut source or preview build are welcome.
Include the commit or build version, platform, steps to reproduce and the
affected file or service. Do not include passwords, tokens or private user
data in a report.

## Report a vulnerability

Check the [repository's Security page](https://github.com/Stormycry-cryp/seecut/security)
for a private reporting option. If it is unavailable, open a
[minimal issue](https://github.com/Stormycry-cryp/seecut/issues) asking the
maintainers to arrange a private reporting channel. Keep vulnerability details
and proof-of-concept files out of the public issue.

Reports may concern local project or media files, downloaded models, account
and team boundaries, remote requests, or the editor's local API. The
maintainers will assess each report against the affected version and provide
updates through the private reporting channel. This repository does not
publish a fixed support window or response-time commitment.
