# Versioned model costs and capped Agent usage

This contract is opt-in. Historical/default Agent budgets remain `verified_input_v1`; historical JSON, policy digests, prices and rounding are preserved. The candidate does not enable production or establish an account procurement price by itself.

`SECUT_ASSISTANT_BILLING_MODE=provider_usage_capped_v1` selects actual supplier usage with a frozen task ceiling. `SECUT_ASSISTANT_PROVIDER_ID` identifies the supplier account route (`bigmodel` for the domestic GLM adapter). `SECUT_MODEL_PRICE_CATALOG_JSON` is a non-secret JSON list of model cost records. A model can be sold only when its exact provider/model/kind record is `verified` or `verified_free`, with a source and RFC3339 verification time. `unknown` and `reference_only` are unavailable; an official reference price does not certify a reseller/account procurement cost.

Each record contains `provider`, `model`, `kind`, `version`, `cost_status`, `source`, `verified_at`, and `costs`. Cost values are decimal strings in yuan. Agent costs have exactly `input`, `cached_input`, `output`, each `{unit: "per_million_tokens", yuan: "…", selectors: {}}`. Ordinary input equals inclusive total input minus verified cached input. The domestic adapter currently accepts explicit `prompt_tokens_details.cached_tokens`, a nonnegative integer no greater than total prompt tokens. Verify that classification contract against the actual account before activation; absent or malformed classification cannot be silently charged as uncached.

Default retail is procurement cost ×3, with 10 credits per yuan. Optional `sale_overrides` give exact decimal **credits per dimension unit** for that provider/model. Versions and all cost/retail provenance are frozen. Nanocredit numerator/denominator strings keep fractional rates exact, including 6.9 credits per million; no floating-point or per-token/step ceiling is used. Synthetic fixture costs and overrides are test data, not account price evidence.

Every new capped budget freezes mode, provider, exact upstream model, independent usage contract, route fingerprint, pricing snapshot/digest, limits and effort digest. No-effort budgets freeze the same contract. Quotes and operations copy the original budget contract; changing live configuration cannot reprice them. New clients can submit `expected_pricing_digest` so a stale choice is rejected before budget creation. Effort catalogs carrying capped metadata use version 3; general transport remains protocol 1. Legacy catalogs/policies omit the added fields.

Preparation stores complete actual wire bytes and SHA256. There is no invented token upper bound or exact advance context-fit guarantee. The historical NOT NULL token-bound SQL column is unused (`-1`) for explicit capped rows; capped execution uses `prepared_payload` and the independent usage contract. Byte, message, tool, output, step and timeout limits remain, and confirmed final context/output overflow settles actual usage within authorization and closes the task.

One immediate transaction holds only the current authorized integer remainder, checking wallet funds, account concurrency and step limits. Confirmed raw supplier usage is priced by the frozen snapshot, accumulated exactly across the task and capped at the authorized raw amount. Display/spent credits are the ceiling of the current task total. Microcredits are derived from that same exact total, preserving `ceil(accrued_microcredits / 1e6) == spent_credits`.

Operations retain raw usage, uncapped amount at frozen retail prices, and the uncollected difference. That difference is **not** supplier procurement cost. Wallet/ledger/hold, exact accrued amount, retail difference and terminal state are committed atomically and idempotently. At exhausted authorization, or confirmed context/output overflow, settlement returns failed with null result, closes the budget and never publishes executable done/tools. No next paid step is allowed. Cancellation likewise suppresses executable results.

Malformed/missing usage, network cuts and uncertain supplier errors keep the original hold and UNKNOWN/pending evidence. Restart and reconciliation inspect the original operation without paid redispatch. Only established no-execution responses release at zero. Local D1 declarations use the same frozen calculator and need independently confirmed evidence plus inclusive input/output and `--cached-input-tokens`; invalid raw cache fields remain audit evidence rather than authoritative conflicts.

Generation procurement pricing is separately opt-in with `SECUT_MODEL_COST_PRICING_ENABLED=true` (default false). Image dimensions use `per_image`; video uses `per_second` or `per_millisecond`, with exact request selectors for size/resolution/other supported parameters. Exactly one dimension must match a normalized request. Quotes freeze the full price contract and original item price; create/replay restore that quote rather than today's catalog. Unknown costs cannot inherit existing zero-price entries. Confirmed free costs are explicitly distinct. Known Agent tiers remain selectable when their generation choices are unavailable.

Acceptance is entirely local and synthetic: HTTP service → private runtime/COTO → MCP, cumulative 0.2+0.2=1 and 0.6+0.6=2, zero usage, exact/exceeded cap, no tool writes at limits, missing cache/malformed/cut usage, restart no resend, cancellation, concurrent holds, D1 and genuine historical fixture migration. Production activation still requires account cost applicability and actual domestic usage contract evidence; real supplier calls require separate authorization.
